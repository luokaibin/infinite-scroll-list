## 特性

- **框架无关**：标准 Web Component，Vue、React、原生页面均可直接使用
- **SSR 安全**：入口在 Next.js 等服务端渲染框架中导入为 no-op
- **无加载竞态**：npm ESM 产物随业务 bundle 打包；CDN IIFE 产物兜底非工程化页面
- **防重复注册**：多入口、多版本场景自动守卫并告警，不抛错
- **持续验证**：契约测试守护分发承诺，组件测试在真实浏览器中验证行为
