`<sticky-sidebar>` 提供响应式吸顶侧栏能力：当视口宽度达到配置的断点时启用吸顶，并自动检测侧栏内容高度——内容高于视口时计算负向 `top` 偏移，保证滚动到底时侧栏内容完整可见；低于断点时自动还原原始样式。

## 使用方式

```html
<div style="display: flex; gap: 20px">
  <div class="main"><!-- 主内容 --></div>
  <sticky-sidebar min-width="1024">
    <div class="sidebar"><!-- 侧栏内容 --></div>
  </sticky-sidebar>
</div>

<style>
  sticky-sidebar {
    position: sticky;
    top: 0;
    transition: top 0.3s ease-in-out;
  }
</style>
```

工作原理：

1. 通过 `matchMedia` 监听视口宽度与 `min-width` 断点的关系
2. 高于断点时检测侧栏内容高度：高于视口则设置 `top = -(内容高 - 视口高)`，低于视口则还原原始 `top`
3. 低于断点时还原原始样式（禁用吸顶偏移）
4. `ResizeObserver` + `window resize`（去抖）+ `requestAnimationFrame` 保证实时响应与性能

## 属性

| 属性名 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `min-width` | Number | `1024` | 吸顶行为生效的最小视口宽度（px）；取值会被校验并收敛到 `0 ~ 3840` |

## 方法

| 方法名 | 参数 | 返回值 | 说明 |
| --- | --- | --- | --- |
| `getBreakpointStatus()` | 无 | `Status` | 返回当前断点状态：`breakpoint`、`currentWidth`、`isAboveBreakpoint`、`mediaQuery`、`isStickyActive` |
| `setBreakpoint(breakpoint)` | `string \| number` | `number` | 程序化设置断点（内部走 `min-width` 属性路径，返回校验后的值） |
| `forceRecalculation()` | 无 | `void` | 强制重新计算吸顶行为 |

## 注意事项

- **无 Shadow DOM**：组件只提供行为，不含任何内部样式——`position: sticky; top: 0;` 等吸顶样式完全由业务侧提供
- 内容高度为 0 或非法时不会应用偏移；断点值超出 `0 ~ 3840` 范围会被收敛并告警
- 迁移说明：源包的开发调试日志（`console.log`）已在迁移时剥离，保留 `warn` / `error` 级诊断
- SSR 安全：入口在服务端渲染框架中导入为 no-op，详见[加载时序与 SSR](../../guides/ssr-and-timing/)
- 浏览器兼容：所有现代浏览器（Chrome / Firefox / Safari / Edge）
