`<tab-indicator>` provides an animated indicator for tab navigation: two effects (underline and capsule), automatic tracking of tab activation, size changes and dynamic add/remove, with smooth transitions. Optional sticky-scroll and smart horizontal scrolling cover complex layouts.

## Usage protocol

Tab items can be any element (`button` / `div` / `p`, …) placed inside the component, driven by two conventions:

- `role="tab-item"`: marks a tab item (nesting at any depth is supported)
- `data-actived="true"`: marks the active item (watched via MutationObserver)

Activation is controlled by the host app (usually `setAttribute` in a click handler); the component handles indicator positioning and animation automatically.

## Attributes

| Attribute | Type | Default | Description |
| --- | --- | --- | --- |
| `effect` | String | `underline` | Indicator effect: `underline` or `capsule` |
| `enable-sticky-scroll` | Boolean | `false` | Enable sticky-scroll support (requires CSS `position: sticky`), see below |
| `smart-horizontal-scroll` | Boolean | `false` | Smart horizontal scrolling: instant positioning on first frame / layout shifts, smooth only on user switches |

## Methods

| Method | Params | Description |
| --- | --- | --- |
| `setScrollTarget(element)` | `HTMLElement` | Manually set the scroll target for sticky scroll; defaults to the component's next sibling element |

## CSS custom properties

| Variable | Default | Description |
| --- | --- | --- |
| `--animation-duration` | `0.3s` | Indicator animation duration |
| `--underline-color` | `#007bff` | Underline color |
| `--underline-height` | `2px` | Underline height |
| `--underline-bottom` | `0` | Underline offset from the bottom |
| `--capsule-bg-color` | `rgba(0, 123, 255, 0.1)` | Capsule background color |
| `--capsule-border-radius` | `999px` | Capsule border radius |

## Sticky scroll (enable-sticky-scroll)

When the component's CSS `position` is `sticky`, enabling this attribute prevents scrolled content from being covered by the stuck tab strip:

1. An `IntersectionObserver` monitors whether the component is stuck
2. The nearest scrollable ancestor is located automatically, and `scroll-padding-top` (top + component height) is set temporarily while switching tabs
3. Scroll positions are cached per active tab and restored when switching back; the original `scroll-padding-top` is restored right after scrolling

```css
tab-indicator {
  position: sticky;
  top: 0;
  background: white; /* recommended to avoid see-through */
}
```

```html
<tab-indicator enable-sticky-scroll><!-- tabs --></tab-indicator>
```
