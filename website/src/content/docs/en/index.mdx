## Highlights

- **Framework-agnostic**: standard Web Components — drop them into Vue, React or plain HTML
- **SSR-safe**: importing the entry is a no-op on the server (Next.js and friends)
- **No loading race**: the npm ESM build ships inside your bundle; a CDN IIFE build covers legacy pages
- **Duplicate-registration guard**: multi-entry / multi-version scenarios are guarded with a warning, never a crash
- **Continuously verified**: contract tests guard the distribution promise, component tests run in a real browser
